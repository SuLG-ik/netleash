# Политика безопасности

Проект устанавливает демон с правами root и setuid-помощника, поэтому сообщения о безопасности воспринимаются серьёзно, но
это не проходивший аудит хобби-проект, который ведётся по мере сил.

## Как сообщить об уязвимости

Используйте **приватные сообщения об уязвимостях** GitHub (репозиторий → *Security* → *Report a vulnerability*).
Не открывайте публичный issue для всего, что можно эксплуатировать. Укажите затронутый компонент, версию macOS и шаги
воспроизведения. **Не включайте личные данные** (IP-адреса, имена пользователей, имена хостов, имена аккаунтов).

Ответ ожидается по мере возможности; сроков и вознаграждения не гарантируется.

## Область

В области: повышение привилегий через `netleash-exec` или демон, способы заставить изолированное приложение выйти в сеть
в обход VPN-туннеля (утечки), способы отключить защиту без прав администратора.

Вне области: атаки, требующие root, скомпрометированная ОС, физический доступ, а также описанные
[ограничения](README.ru.md#ограничения) (ICMP, процессы, запущенные через launchd, DNS других приложений и т. д.).
