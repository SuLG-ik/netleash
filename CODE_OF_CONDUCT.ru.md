# Правила поведения

Будьте уважительны и конструктивны. Недопустимы травля, личные нападки, спам, требования поддержки или функций и
публикация чужих личных данных.

Сопровождающий вправе редактировать, скрывать, закрывать для обсуждения или удалять комментарии, issue и pull request'ы и
блокировать пользователей по своему усмотрению и без предупреждения. Решения о том, что принимать, принадлежат только
сопровождающему.

О нарушениях со стороны участника сообщайте через функцию GitHub *Report content*.
