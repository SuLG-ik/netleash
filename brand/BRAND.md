# Netleash brand (draft for review)

## Idea
A **leash**: a handle loop on the left, a lead running to a node on the right, and a thin boundary ring around the node —
the application, kept inside the route you allow. The wordmark is drawn as a single-weight rounded line (like a leash);
the **l** carries the accent colour.

## Palette
| Name | Hex | Use |
|---|---|---|
| Leash Navy | `#0B1B33` | text on light, dark backgrounds |
| Deep Navy 2 / 3 | `#10284A` / `#08152A` | app icon gradient |
| Tunnel Teal | `#14B8A6` | primary accent |
| Signal Mint | `#5EEAD4` | node, highlights on dark |
| VPN-up Green | `#2DD4A0` | menu bar: VPN connected |
| Alert Coral | `#FF5D73` | menu bar: VPN down, app blocked (cut leash) |
| Caution Amber | `#FFB020` | menu bar: protection not working |
| Mist / Slate | `#E6F0F5` / `#7B8BA3` | light backgrounds, secondary text |

## Files
- `svg/` editable sources (generated by `generate.py`); `png/` rendered images; `Netleash.icns` the macOS app icon
- `icon` — app icon · `mark` / `mark-dark` — symbol only · `logo-horizontal(-dark)` — symbol + wordmark
- `menubar-up|down|warn` — status glyphs (18 pt, @2x provided); `social-preview` — GitHub 1280×640
- `render.sh` regenerates everything (macOS: uses AppKit's SVG renderer)

## Rules
Keep clear space equal to the node's diameter around the mark. Do not recolour the mark outside the palette, rotate it,
or add effects. Not affiliated with Anthropic or Amnezia; do not combine the mark with their names or logos.
